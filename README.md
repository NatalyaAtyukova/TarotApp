# TarotApp

Android app written in Kotlin.

## Status

Portfolio project.

## Tech

- Kotlin
- Android Gradle

## Run locally

1. Clone the repository:
```bash
git clone https://github.com/NataliaAtiukova/TarotApp.git
cd TarotApp
```
2. Open in Android Studio.
3. Sync Gradle and run on emulator/device.

## Notes

Main Android module is in `app/`.
